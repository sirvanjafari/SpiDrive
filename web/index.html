    Settings
    SpiDrive was started from the command line, so these settings come from config.py. Change them there and restart.

    Drive

    Telegram has no storage limit; this is only the number Windows displays (for example 10T or 500G).

    Two-way sync

    Folders on this PC kept in sync with folders on the drive.

    Connection to Telegram

    MTProxy links (tg:// or t.me/proxy), SOCKS5 or HTTP.
    Proxy lists used by Automatic
    One address per line. Lists of plain ip:port start with socks5+, for example socks5+https://…/proxy.txt

    General
